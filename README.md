# GM Scripts

用于存放和维护个人 GM / Userscript 脚本，适用于 Stay、Tampermonkey 等脚本管理器。

| 脚本 | 功能 | 安装 |
| --- | --- | --- |
| [Apple 美国商店购物及结账中文翻译](apple-giftcard-zh.user.js) | 翻译礼品卡、购物袋、配送与结账页面 | [安装脚本](https://raw.githubusercontent.com/1clxiso/gm-scripts/main/apple-giftcard-zh.user.js) |

打开安装链接后交给脚本管理器安装；Stay 也可以使用链接导入。脚本已配置当前仓库的更新地址，后续更新是否自动安装取决于脚本管理器设置。

## Apple 美国商店购物及结账中文翻译

脚本：[apple-giftcard-zh.user.js](apple-giftcard-zh.user.js)，当前版本 **1.2.6**。

## Safari + Stay 安装或更新

1. 在 Stay 中打开原脚本，用本文件的全部代码替换，保存并启用。只保留一个启用的版本。
2. 在 Safari 中启用 Stay，并允许访问 Apple 商店网站。
3. 刷新当前页面。进入安全结账页面时，如果 Safari 提示新的域名权限，请允许 Stay 在该 Apple 网站运行。
4. 默认显示简体中文，右下角可随时切回英文。登录框等内嵌页面自动翻译，不另显示按钮。

Tampermonkey 也可以导入同一份脚本。

## 页面范围

- `www.apple.com/shop/*`、`www.apple.com/us/shop/*`：礼品卡配置及其子路径、商品页、购物袋等。
- `*.store.apple.com/*`、`store.apple.com/*`：安全结账、登录选择、配送、收货地址、付款、订单核对及订单页面。包括 `secure9.store.apple.com` 等数字分流域名。
- `idmsa.apple.com/appleauth/*`：内嵌 Apple 账户登录与验证界面。
- `account.apple.com/*`、`appleid.apple.com/*`：相关 Apple 账户网页。

新版补充购物袋、Check Out、Apple Pay 结账入口、访客结账、地址、配送日期、账单、银行卡字段、税费、错误提示与订单文案。网址中的动态参数及同页切换不会阻止翻译。

## 行为与限制

- 使用本地词典，无外部翻译请求，不上传输入内容。
- 不更改输入框或文本域的值、密码、银行卡信息、金额、币种、链接或按钮事件；不自动填写、不提交订单。
- 下拉选项仅在已明确声明 `value` 时翻译显示文字，保持提交值。没有 `value` 的选项保持原文，避免改变表单数据。
- Apple Pay 网页按钮通过官方 `lang` / `locale` 设置中文；Safari / iOS / macOS 的原生付款面板及银行验证界面不受网页脚本控制，其语言由系统和服务提供方决定。
- 中文辅助理解，条款可切回英文核对。未收录的新文案、图片内文字、第三方付款页面可能保持原文。没有发生真实付款，付款与订单成功页尚未全流程实测。
- 中英文切换按当前页面生效；独立登录 iframe 默认中文。

## 1.2.2 补漏

- 补齐购物袋组合配送说明、移除商品通知、客服片段、页脚链接、登录验证与付款提示。
- 支持带标点的标签、完整星期／月份、工作日配送期限和更多无障碍提示。
- 月份仅在配送日期与显式选项中翻译，避免把联系人 May / June 等姓名译为月份。
- 可运行的本地回归页面见 [tests/README.md](tests/README.md)，覆盖 40 项行为检查。

## 1.2.3 付款与订单确认补充

- 补充持卡人、到期日、安全码、账单地址、余额、付款授权／失败、订单核对、电子礼品卡发送、发票与退款状态等候选文案。
- 新增金额、卡尾号、订单编号、确认邮件和收据邮箱等动态模板。保留其动态数据及大小写，不将等待授权或处理中误译为付款成功。
- 增加 42 条付款／订单模板案例，浏览器回归检查扩展至 84 项，并提供无依赖的 Node 检查。
- 本轮未使用真实银行卡、未执行付款、未生成真实订单。候选文案和本地场景用于补充覆盖，不代表真实付款页面已经逐项验证。

参考 Apple 的公开 [付款说明](https://www.apple.com/shop/help/payments) 和 [订单状态说明](https://www.apple.com/shop/help/viewing_changing_orders)。部分词条是为可能出现的界面变体补充的候选项。

## 1.2.5 紧急回退

收到 Safari + Stay 中 v1.2.4 整体失效的反馈后，恢复 v1.2.3 的脚本逻辑，仅提升版本号以便正常更新。撤回 v1.2.4 的原生弹窗函数接管、多行翻译和新错误模板。保留此前购物袋、配送、付款和订单页面的翻译。

具体根因仍待用户环境确认；本地模拟对话框测试不能代表 Safari + Stay 兼容性。原生 alert / confirm / prompt 不再由脚本改写。

## 1.2.6 网页错误与弹窗翻译

- 以用户确认可用的 v1.2.5 为基础，仅增加错误词条与明确的校验模板；启动、DOM 遍历、监听、语言切换保持不变。
- 补充必填项、格式错误、金额／字符限制、验证码、网络／会话超时、付款失败和订单取消确认等网页内提示。
- 不改写、不调用 `alert` / `confirm` / `prompt`，不修改表单提交或校验 API。Safari 系统弹窗和原生提示仍跟随系统语言。
- 132 项本地浏览器回归检查覆盖动态网页弹窗、关闭按钮、表单约束、错误引用关系、英文恢复和原生函数引用不变。
- 未知的新文案可能仍保留英文。本地测试不替代用户 Safari + Stay 环境验证；本版没有重新引入 v1.2.4 的原生弹窗接管或递归多行处理。
